# 第 1 课：文字角色移动

## 学习目标

本课把角色移动写成确定性的状态转换：给定当前位置、动作和地图尺寸，得到下一个位置，并进一步记录多步移动轨迹。

本课逐步学习：

- 二元组、解包与坐标；
- 列表、`append` 和 `for` 循环；
- 当前状态、动作、下一状态与轨迹；
- 非法输入与合法但受阻动作的区别；
- 复用函数，避免重复实现规则；
- 用自动测试保护边界行为。

## 坐标约定

- `(0, 0)` 位于地图左上角；
- `x` 向右增加，`y` 向下增加；
- `"up"`：`y - 1`；
- `"down"`：`y + 1`；
- `"left"`：`x - 1`；
- `"right"`：`x + 1`。
- `"stay"`：位置保持不变。

## 单步移动规则

`move_character` 接收当前位置、动作、地图宽度和地图高度，返回移动后的新位置。

1. `width <= 0` 或 `height <= 0`，抛出 `ValueError`；
2. 初始位置不在地图范围内，抛出 `ValueError`；
3. 动作不是 `"up"`、`"down"`、`"left"`、`"right"`、`"stay"`，抛出 `ValueError`；
4. 合法移动不会超出地图边界；
5. 如果动作会撞到边界，角色保持原位置，这不是异常。

## 多步移动规则

`execute_commands` 从起点依次执行动作并返回完整轨迹。

- 轨迹必须包含初始位置；
- 每执行一个动作，都向轨迹追加一次状态；
- 撞到边界时也要追加保持不变的位置；
- 轨迹长度始终等于动作数量加一；
- 即使动作列表为空，也必须校验地图尺寸和起点。

## 学习顺序

1. 先完成坐标口算，不写代码；
2. 实现地图内部的四方向单步移动；
3. 加入非法输入校验和边界处理；
4. 重构动作与坐标变化的映射；
5. 实现多步轨迹；
6. 增加边界测试并完成现场需求修改。

不要提前实现尚未讲解的步骤。每一步通过测试和代码审查后再继续。
