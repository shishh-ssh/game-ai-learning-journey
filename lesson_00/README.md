# 第 0 课：NPC 决策函数

## 学习目标

本课只学习五件事：函数、参数、返回值、条件判断和异常。

`npc_policy.py` 中有一个尚未实现的 `choose_action` 函数。它接收 NPC 的生命值、敌人距离和敌人是否可见，返回一个行为字符串。

## 行为规则

规则从上到下具有优先级：

1. `distance < 0` 或 `health` 不在 `0` 到 `100`，抛出 `ValueError`；
2. `health == 0`，返回 `"dead"`；
3. 看不到敌人，返回 `"patrol"`；
4. `health <= 30`，返回 `"flee"`；
5. `distance <= 2`，返回 `"attack"`；
6. 其他情况返回 `"chase"`。

## 任务步骤

1. 阅读 `npc_policy.py` 的函数签名和说明；
2. 先用中文或伪代码写出判断顺序；
3. 实现函数，不修改测试；
4. 运行测试并独立处理第一次报错；
5. 测试通过后等待代码审查，不提前做下一课。
